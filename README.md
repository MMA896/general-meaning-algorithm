# خوارزمية البحث عن المراد / المعنى العام — إصدار الاستبدال 2.0.0

## ما يفعله هذا الإصدار
- بحث باللفظ بعد تطبيع بعض أشكال الألف والياء وإزالة التشكيل.
- بحث باللمّة أو الجذر حسب حقول المصدر، وبحث حرفي داخل الصيغ.
- استيراد بيانات Quranic Arabic Corpus morphology v0.4 إلى SQLite وفهرستها.
- إحصاء الصيغ والجذور واللمّات والأنواع الصرفية والحروف والكلمات السابقة واللاحقة.
- عرض مواضع السورة والآية والكلمة والجزء، مع سياق الجوار داخل الآية بحسب ترتيب الوحدات في المصدر.
- سجل عمليات البحث، وحالة خدمة قابلة للفحص عبر `/health`.
- ترحيل آمن للأعمدة الناقصة في جدول `runs`.

## النشر على Render
الإعداد الحالي للموقع يستخدم `pip install -r requirements.txt` و`gunicorn app:app`.
لا تستبدل إعدادات البيئة الحالية بكاملها. تأكد من ضبط `RESEARCH_USER` و`RESEARCH_PASSWORD` و`SECRET_KEY` من إعدادات Render.
إذا كان لديك قرص دائم، اضبط `DATABASE_PATH` على مسار داخل القرص؛ وإلا قد لا تبقى قاعدة SQLite بعد إعادة إنشاء الخدمة.

## مصدر البيانات وحدوده
المصدر: https://raw.githubusercontent.com/bnjasim/quranic-corpus/master/quranic-corpus-morphology-0.4.txt
المصدر يوفر طبقة تحليل صرفي ومواضع، وليس نص الآيات الكامل. لذلك لا يعرض التطبيق الآية كاملة، ولا يزعم أن المطابقة وحدها تثبت علاقة دلالية أو تفسيرًا شرعيًا.
المصدر الخارجي يحتاج اتصالًا أثناء أول فهرسة إذا لم يكن ملف البيانات موجودًا محليًا. إن تعذر الوصول إليه، يعرض النظام خطأ واضحًا بدل اختلاق نتائج.
